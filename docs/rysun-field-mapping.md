# Rysun Azure DevOps Resource Timesheet Mapping Reference

## Work Item Type
- **Type Name**: `Resource Timesheet`
- **Default Iteration**: `Rysun Project Management`

## Standard Field Mappings

| UI Field Name | Field Type | Azure DevOps Reference Field Name | Default / Example Value |
|---|---|---|---|
| **Title** | System | `System.Title` | `[User Name] - YYYY-MM-DD` |
| **Area Path** | System | `System.AreaPath` | `Rysun Project Management\VC - VCQMS` |
| **Iteration** | System | `System.IterationPath` | `Rysun Project Management` |
| **Assigned To** | System | `System.AssignedTo` | Logged-in user resolved identity email/display name |
| **Client Name** | Custom | `Custom.ClientName` | `Visual Comfort and Co` |
| **Project** | Custom | `Custom.Project` | `VCC - VCQMS Enhancements and InspectionDB` or `VCC - RMA Modernization` |
| **Date** | Custom | `Custom.Date` | `YYYY-MM-DD` |
| **Day** | Custom | `Custom.Day` | `Monday`, `Tuesday`, `Wednesday`, `Thursday`, `Friday` |
| **PH** | Custom | `Custom.PH` | `No` (or `Yes` for Public Holiday) |
| **Leave** | Custom | `Custom.Leave` | `No` (or `Yes`) |
| **Half Day** | Custom | `Custom.HalfDay` | `No` (or `Yes`) |
| **WFH** | Custom | `Custom.WFH` | `No` (or `Yes`) |
| **Hours** | Custom | `Custom.Hours` | `8.0` (confirmed by user) |
| **Task Summary** | Custom | `Custom.TaskSummary` | Editable summary generated by Gemini AI (Markdown / README format with - bullet items) |

## Idempotent Validation Logic

Before submitting to Rysun:
1. Execute WIQL query checking for existing work items with `[System.WorkItemType] = 'Resource Timesheet'` and title matching `[User Name] - [Date]`.
2. If match found:
   - Present status `Already Submitted` or prompt user for explicit update confirmation.
   - Prevent accidental duplicates.
3. If no match found:
   - Create work item via REST API version 7.1.
